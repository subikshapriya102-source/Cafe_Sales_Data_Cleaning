Cafe Sales Data Cleaning – Task 1

Project Overview

This project focuses on cleaning and validating a Cafe Sales dataset using Microsoft Excel.

Dataset

- Original dataset: Cafe Sales
- Total records: 10,000
- Tool used: Microsoft Excel

Sheets in the Workbook

1. dirty_cafe_sales – Original dataset (unchanged).
2. dirty_cafe_sales1 – Cleaned dataset.
3. Missing Values Summary – Summary of blank and unknown values.

Data Cleaning Steps

1. Checked data types and data consistency.
2. Identified and reviewed missing values.
3. Checked and handled error values using helper columns and formulas.
4. Reviewed unknown values in Payment Method and Location.
5. Checked for duplicate records. No duplicates were found.
6. Performed data validation.
7. Checked for negative values and formula errors.
8. Created a Missing Values Summary sheet.

Conclusion
